# Official Microsoft architecture assets

These SVGs are unmodified originals from Microsoft's official downloadable architecture icon sets, retrieved on 20 September 2026. They are used to illustrate the actual Microsoft services in EntraGuard's solution architecture. The Azure symbol identifies the hosting platform, not the EntraGuard product.

## Sources and permissions

- **Azure Public Service Icons V24:** [Microsoft Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/icons/), [official ZIP](https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip).
- **Microsoft Entra architecture icons, October 2023:** [Microsoft Entra architecture icons](https://learn.microsoft.com/en-us/entra/architecture/architecture-icons), [official ZIP](https://download.microsoft.com/download/3/1/a/31a56038-856a-4489-88e4-ee5a1c4352be/Microsoft%20Entra%20architecture%20icons%20-%20Oct%202023.zip).

Microsoft permits use in architectural diagrams, training materials and documentation; Microsoft reserves all other rights. These third-party assets are subject to Microsoft's terms, not the repository's code license. See the source pages for the full usage guidance. Icons retain their original shapes and colors and are proportionally scaled, without cropping, flipping or rotation.

## Editing and export

Edit `../hackathon-architecture.source.svg`, then run from the repository root:

```sh
node scripts/render-hackathon-architecture.cjs
```

The existing `src/portal` dependencies provide `sharp`. The script embeds each original SVG as a data URI in the standalone diagram and exports Full HD and 4K PNGs. Both image outputs are self-contained; the `.source.svg` uses these local files for convenient editing.

The detailed logical/flow pack is generated by `node scripts/render-architecture-flows.cjs`. It exports nine 3200 × 1800 diagrams, a browsable HTML gallery and the step-by-step guide in `docs/architecture-flows.md`. Sequence content is editable in `docs/diagrams/flows/flow-definitions.json`.
